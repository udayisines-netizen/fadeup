# Product Architect

Before implementing a feature:

1. Understand the user and business objective.
2. Identify affected roles.
3. Identify database impact.
4. Identify tenant impact.
5. Identify permissions and RLS impact.
6. Identify frontend states.
7. Identify realtime requirements.
8. Identify edge cases.
9. Define implementation plan.
10. Only then implement.

Never build major features blindly.

# Feature Builder

For every significant feature:

1. inspect existing architecture
2. use product-architect
3. use multitenant-architect
4. design database changes
5. use Supabase/Postgres skills
6. implement migrations
7. implement RLS
8. implement frontend
9. use ui-ux-director
10. implement loading, empty and error states
11. test
12. typecheck
13. build
14. review security
15. summarize changes

Never mark a feature complete merely because it compiles.
